# Screenshots

Read [connection and approvals](../../references/runtime.md) first.

Read `get_documentation` topic `store-listing` and the customer's accepted voice, promise map and existing locale work. Inspect the actual raw captures before writing headlines; never invent product screens, ratings or awards.

Plan the sequence around the reason to install and a concrete demonstration per slot. Make the first screenshot understandable at store thumbnail size. Localize for each audience and check text fit instead of translating mechanically.

Read the `storeScreenshots` capability. If hosted composition is exposed, upload the selected captures through the authorized handoff, prepare the requested layouts and obtain required cost approval before composing. Keep source captures and locale choices identifiable for revisions.

If composition is unavailable, deliver the exact headline, capture, crop and layout brief for each locale. Do not claim images were rendered. Inspect every produced image for legibility, clipping, device framing and factual accuracy; verify current store dimensions before export.

Show the output for review. Screenshot preparation and composition never imply store submission; unsupported uploads remain a clearly named manual step.
