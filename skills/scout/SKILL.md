# Scout

Read [connection and approvals](../../references/runtime.md) first.

Start with the product, audience and research question; reuse a niche the user already specified. Use host search, ordinary authorized browsing and supplied exports. Do not install a local research server or extract sessions, cookies or blocked media.

Record account and post links, collection dates, visible counts and the sample window. Compare similar formats and markets. Inspect the spread of per-post results before calling a format successful; one viral post can distort an average. A quiet window does not prove an account is dead.

For a teardown, explain the hook, progression, visual structure, payoff and audience response in original words. Competitor artwork is evidence for analysis, never an asset for the user's next post. Rebuild a useful structure with the customer's own material.

Use public ad libraries to describe visible creative and destinations. Do not infer private spend, conversions or profitability from an ad's continued presence.

Stop at denied access or platform challenges; use accessible evidence or an authorized export. Report findings with links, measured observations, limitations and a concrete creative implication. If no research access exists, say what evidence is still needed; do not fabricate a sample.
