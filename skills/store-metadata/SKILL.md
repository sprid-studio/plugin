# Store Metadata

Read [connection and approvals](../../references/runtime.md) first.

Read `get_documentation` topic `store-listing` before writing. Fetch the current public listing or use the customer's supplied export; preserve accepted positioning and existing locale-specific work.

Inspect name, subtitle, keywords and description against the guide's current field limits. Use each locale's own search evidence and vocabulary. Keep useful search terms based on evidence, not a universal rule about duplication. Do not invent ratings, customer counts or unsupported product claims.

Prepare exact before/after values per locale, with the reason for each change. Use the customer's voice and distinguish literal source quotes from new copy. Validate lengths and identify fields a release state prevents changing.

Check `storeMetadata` capabilities. Use the exposed preparation tools where available; publishing store copy may require manual completion in the store console. Never describe a saved draft or prepared execution as submitted or public. The person reviews exact changes before any supported external write.
